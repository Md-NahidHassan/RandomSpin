# 🎯 RandomSpin (Lucky Draw / Winner Picker)

[![Deployed on Vercel](https://img.shields.io/badge/Deployed%20on-Vercel-black?logo=vercel)](https://vercel.com/md-nahidhassans-projects/random_spin)

A highly interactive, visually stunning, and dynamic **Random Winner Picker** web application built with pure Vanilla JavaScript, HTML5, and CSS3. 

**🔗 Live Dashboard / Demo:** [Visit on Vercel](https://vercel.com/md-nahidhassans-projects/random_spin)

This project features a breathtaking live galaxy background, glassmorphism UI, a mathematically accurate spinning wheel, and local storage state persistence.

## ✨ Features
- **Dynamic Spinning Wheel:** Automatically resizes slices based on the number of participants.
- **Fair Randomization:** Complete mathematical accuracy for randomized winner selection.
- **Auto-Removal System:** Selected winners are automatically moved to the "Winners List" and removed from the active spinning pool.
- **Live 3D Galaxy Canvas:** Interactive flying stars with a slow-rotating aesthetic galaxy background.
- **Responsive Design:** 100% Mobile, Tablet, and Desktop ready.
- **State Persistence:** Participant and winner data is saved to `localStorage` (No data lost on page refresh).
- **Sound & Effects:** Confetti celebrations and tick sounds during spinning.

## 🚀 How to Run Locally
Because this project uses vanilla HTML, CSS, and JS, no complex server is required. 
Simply open `index.html` in any modern web browser!

## 🌐 Deploying to Vercel
Deploying this project is extremely easy since it consists purely of static files.

1. Create a free account on [Vercel](https://vercel.com).
2. Connect your GitHub account.
3. Click **Add New** → **Project**.
4. Select the `RandomSpin` repository from your GitHub account and click **Import**.
5. Do not change any build settings (Vercel automatically detects static HTML files).
6. Click **Deploy**.

Within seconds, your Live Galaxy Lucky Draw will be globally hosted and ready to share!

## 🛠 Technologies Used
- HTML5 (Semantic Structure & Canvas)
- CSS3 (Variables, Flexbox/Grid, Animations, Glassmorphism, Media Queries)
- Vanilla JavaScript (ES6, Canvas API Context 2D, LocalStorage API)
